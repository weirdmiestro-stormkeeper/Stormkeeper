Stormkeeper Character Sheet

Open index.html for a quick local preview. For install/offline PWA behavior, host the folder on HTTPS (for example GitHub Pages, Cloudflare Pages, or Netlify), then open that URL on the Kindle, phone, or computer.

Character data is stored locally in the browser and can be exported/imported as JSON.
This starter does not reproduce full copyrighted 5e books; it contains the current character data and core sheet functionality.
