Stormkeeper V19 — Compendium Pass

V19 expands the in-app reference into clickable rule cards for classes, subclasses, species, backgrounds, armor, weapons, spellcasting concepts, conditions, actions, feats, and adventuring rules. Character-sheet armor/weapon references and class feature references are clickable.

This build keeps the phone-friendly root-file deployment model. Replace index.html, app.js, main.css, sw.js, and manifest.webmanifest. Leave existing JSON data files in place.

Rules content is a concise Stormkeeper reference based on the SRD foundation and original summaries; it is not a reproduction of non-SRD book text.
