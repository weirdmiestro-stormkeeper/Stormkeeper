# Stormkeeper V11

V11 integrates the rules catalog with the existing character builder.

Included:
- Unified races/species catalog
- Background catalog
- Class catalog
- Subclass catalog with campaign/custom entries clearly marked
- Armor catalog
- Weapon catalog
- Spell catalog
- Source labels
- In-app Rules Library
- SRD 5.1 CC-BY-4.0 attribution
- Existing V10 level, mechanics, spell, and character systems preserved

Legal approach:
- SRD-derived entries are identified as SRD.
- User/campaign additions are marked Custom.
- Full non-SRD book text is not copied into the application.
