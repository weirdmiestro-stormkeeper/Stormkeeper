Stormkeeper V18 — Description Pass

This build expands the guided character builder so every currently supported class, species, and background choice has a fuller overview before selection. Existing rules-database fields are preserved and take precedence where present.

V18 also shows class role, subclass-path context, background flavor and typical gear, while keeping subclass selection locked until the appropriate class level.
