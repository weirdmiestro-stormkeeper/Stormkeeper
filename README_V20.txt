V20 adds a complete class profile layer for all 12 core SRD foundation classes:
Barbarian, Bard, Cleric, Druid, Fighter, Monk, Paladin, Ranger, Rogue, Sorcerer, Warlock, Wizard.

Each class now has a role summary, proficiencies/skill choices where applicable, starting equipment support, subclass paths, and a level-progression reference. Existing local class JSON data is preserved and can override/enrich the fallback data.

Subclasses remain locked until the class reaches the appropriate level.
